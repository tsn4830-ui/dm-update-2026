# 糖尿病治療更新：華盛頓內科治療手冊 第37版 vs 第38版 vs ADA 2026

單檔靜態網頁，供離線瀏覽或自行上傳至 GitHub Pages。內容對照 Washington Manual of Medical Therapeutics 第23章第37版、第38版與 ADA Standards of Care 2026，依已校正投影片整理，未新增臨床主張。

## 檔案

- `index.html`：完整網頁（樣式與流程圖皆內嵌，不需網路、不需外部腳本）。
- 本說明檔。

用瀏覽器直接開啟 `index.html` 即可閱讀。文獻連結指向外部網站，離線時無法開啟目標頁；VitalSource 電子書需登入後才能閱覽。

## 上傳到 GitHub Pages

1. 在 GitHub 開一個新的儲存庫（repository），可公開或私有（私有儲存庫的 Pages 需符合帳號方案）。
2. 將 `index.html` 上傳到儲存庫根目錄（也可放在 `docs` 資料夾）。若希望網址為 `https://帳號.github.io/儲存庫名稱/`，檔名必須是 `index.html`。
3. 開啟儲存庫的 **Settings → Pages**。
4. Source 選 **Deploy from a branch**，分支選 `main`（或你使用的分支），資料夾選 `/ (root)` 或 `/docs`（需與上傳位置一致），儲存。
5. 數分鐘後即可用 GitHub 提供的網址開啟。之後更新只要再上傳新的 `index.html`。

不需要安裝 Node、不需要執行建置指令。
